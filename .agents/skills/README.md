# Project skills

The engineering and productivity skills used by this project are from [mattpocock/skills](https://github.com/mattpocock/skills/tree/6f7f7831a625f040a8e06a0e7954826b87ce775a). The license is in [LICENSE](LICENSE). The files are available from a fresh checkout.

To refresh the selection with the Skills CLI for Codex, run this command at the repository root:

```sh
npx skills@latest add mattpocock/skills --agent codex --skill ask-matt code-review codebase-design diagnosing-bugs domain-modeling grill-with-docs implement-spec implement improve-codebase-architecture pr prototype research retro setup-matt-pocock-skills tdd to-spec to-tickets triage wayfinder wizard grill-me grilling handoff teach to-questionnaire wait-what writing-for-agents --yes
```
