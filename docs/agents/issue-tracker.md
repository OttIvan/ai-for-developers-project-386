# Issue tracker: GitHub

Трекер проекта — [GitHub Issues](https://github.com/OttIvan/ai-for-developers-project-386/issues). Репозиторий `OttIvan/ai-for-developers-project-386` используйте также в GitHub CLI или в подключении к GitHub. Перед публикацией проверьте, что выбрали этот репозиторий.

- Карта решений, спецификация и каждый тикет оформляются отдельными задачами GitHub Issues.
- Привязывайте тикет к карте или спецификации через подзадачи GitHub. Если привязка недоступна, укажите `Part of #<номер>` в начале тикета.
- Отмечайте блокировки штатными зависимостями GitHub. Если этот способ недоступен, добавьте `Blocked by: #<номер>` в начало тикета. Открытый блокирующий тикет означает, что зависимая задача ещё не готова к работе.
- Для карты и её дочерних тикетов используйте метки `wayfinder:map` и `wayfinder:<type>` по мере их создания. Метки разбора задач заданы в [triage-labels.md](triage-labels.md).
