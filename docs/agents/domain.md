# Domain docs

У приложения один контекст. Словарь предметной области ведём в `GLOSSARY.md` в корне репозитория, записи об архитектурных решениях — в `docs/adr/`.

Перед работой прочитайте словарь и ADR по теме задачи, если они уже появились. Используйте термины из словаря в спецификациях, тикетах и тестах. Если предложение расходится с принятым ADR, укажите номер решения и объясните расхождение.

Пополняйте словарь и ADR по мере согласования терминов и решений.
