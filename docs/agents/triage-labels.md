# Triage labels

| Роль в скилле | Метка GitHub Issues | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Задача ждёт разбора |
| `needs-info` | `needs-info` | Нужны уточнения |
| `ready-for-agent` | `ready-for-agent` | Задача готова к реализации агентом |
| `ready-for-human` | `ready-for-human` | Задача требует работы человека |
| `wontfix` | `wontfix` | Задачу решили не брать в работу |
