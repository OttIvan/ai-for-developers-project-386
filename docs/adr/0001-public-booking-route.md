# Публичная страница записи по отдельному адресу

Главная по адресу `/` знакомит гостя с сервисом и ведёт на публичную страницу записи `/book`. Отдельный адрес выбран вместо встраивания записи в главную, чтобы ссылкой на запись можно было делиться напрямую и чтобы добавление каталога типов встреч не меняло адрес. До реализации бронирования по `/book` доступна заглушка со ссылкой на главную.
